Privacy

What you type stays on your Mac

Dấu never sends what you type anywhere. macOS blocks the part of Dấu that reads your keys from the internet entirely.

The part that reads your keys

runs whenever you type

macOS blocks it from the internet, so it cannot send what you type anywhere.

It runs in a macOS sandbox.

The downloadable build keeps no record of what you type, in which app, or when.

The two parts share only settings, such as Telex or VNI, never what you type

The Dấu app

the settings window

Goes online only to check for and download updates. The list of compatible apps comes with the install; the list isn’t downloaded separately.

Report a Problem opens a prefilled GitHub page. You review it and send it yourself.

Dấu collects no usage data.

Open source. Anyone can read all of the code on GitHub (GPLv3 license) and build it themselves.
This site only counts visits and button clicks. No cookies, nothing that identifies you. The counts are kept at Vercel, which hosts the site.

FAQ

Common questions

Is Dấu free?+

Yes. It’s completely free and open source under the GPLv3 license. There’s no paid version and no ads.

Does Dấu collect what I type?+

No. The input method can’t access the network, so it can’t send anything out. Dấu sends no usage data; you send problem reports yourself.

Does it need permissions?+

No Accessibility access needed. The first time you turn Dấu on, macOS may ask “Allow “Dấu” to enable “Dấu”?”, since an input method receives every key you type. Click Allow.

How does it differ from the built-in Vietnamese input?+

The built-in one underlines the word you’re typing; Dấu changes letters in place, as shown in Three ways to type Vietnamese. Verified correct in Antigravity, Firefox, Google Chrome, Mail, Microsoft Edge, Notes, Notion, Obsidian, Safari, Sublime Text, Telegram, TextEdit, Visual Studio Code, Word on the web, and Zed (macOS 27).

I use another input method. How do I switch?+

When you first open Dấu, it finds an old input method still running and shows how to turn it off, since two running at once garble text.

Why no macros, auto-capitalization, or encoding conversion?+

Dấu deliberately skips what macOS already does and what makes an input method more complex. If you used these elsewhere:

  • Macros: use Text Replacements… in System Settings › Keyboard.
  • Auto-capitalization: turn on Capitalize words automatically in macOS.
  • Switching Vietnamese/English per app: turn on Automatically switch to a document’s input source, and each window remembers its own input source.
  • Legacy encodings, converters: Dấu outputs standard Unicode only.
  • Custom switch key, custom icon, switch sounds: Dấu uses the macOS input source shortcut and icon.
  • Typing statistics: Dấu doesn’t record what you type.
In VNI, why do digits turn into marks?+

In VNI, a digit typed right after a Vietnamese syllable is a mark key: lan2 gives làn. To keep the digit, type it twice: a11 gives a1. Standalone numbers, like 2024, stay as they are.

An app won’t let you choose Dấu?+

That app may still have an old list of input sources from before Dấu was installed. Log out (Apple menu › Log Out) and log back in once: when apps open again, each one reads the list again. Just quitting and reopening the app isn’t enough.

How do I uninstall Dấu?+

Open Dấu, go to Updates & Support, and click Uninstall…. Dấu opens the Input Sources list in System Settings for you: select “Dấu – Vietnamese” and click “–”. Once Dấu is off the list, Dấu moves the input method and then the app itself to the Trash, and quits. If you don’t click “–”, nothing is removed.
